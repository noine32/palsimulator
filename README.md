# PalBreeder Web v0.2

GitHub Pages版のPalworld配合プランナーです。

## v0.2

- 通常配合フローチャートのノード重なり対策
- 最大4パッシブ継承タブを復帰
- パッシブプリセットを復帰
- 所持個体のパッシブ供給元チェック
- パッシブ継承ルート候補
- パッシブ継承フローチャート
- パッシブフローチャートPNG保存

## データ保護

`owned_pals.json` はブラウザ内でのみ読み込み、GitHub Pagesや外部サーバーへアップロードしません。

セーブデータ、NAS/SMB情報、認証情報、各種トークンはリポジトリへ保存しません。

## 公開

GitHub Pages: `main` / `/ (root)`

## 注意

パッシブ継承にはゲーム内のランダム性があります。表示するルートは血統を組み上げるための候補であり、必要な卵数を保証するものではありません。
