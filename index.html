    クラウド同期

    本人用トークンで、自分の所持データだけを取得します。

    共有PCでは「この端末に保存」を使わないでください。保存時はブラウザのlocalStorageに保持されます。

    データの扱い

    ローカルJSONを選んだ場合、そのファイルは外部へアップロードしません。 ブラウザ内メモリだけで処理します。

    クラウド同期を使う場合は、自宅Readerが本人用の最小JSONだけをCloudflare WorkerへHTTPS送信し、本人用Read TokenでそのプレイヤーのJSONだけを取得します。

    「この端末にトークンを保存」を有効にした場合のみ、そのRead TokenをこのブラウザのlocalStorageへ保存します。共有PCでは有効にしないでください。

    GitHub Pagesにはセーブデータ、NAS情報、SMB認証情報、Push Secret、プレイヤーJSON、Read Tokenを保存しません。
